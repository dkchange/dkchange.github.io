# 主機管理

## 前言

主機管理涵蓋多個層面，從實體機器到虛擬化技術，每個階段都有其優缺點：

| 類型     | 說明                      | 優點         | 缺點               |
| -------- | ------------------------- | ------------ | ------------------ |
| 實體機器 | 直接在硬體上安裝作業系統  | 效能最佳     | 環境衝突、資源浪費 |
| 虛擬機   | 在作業系統上虛擬另一個 OS | 環境隔離     | 資源消耗大         |
| 容器     | 共享核心，以進程為單位    | 資源利用率高 | 隔離性較弱         |

根據需求選擇合適的方案，是主機管理的第一步。

## 網路儲存掛載

當需要跨伺服器共享資料時，網路儲存是常見解決方案。常見的網路儲存協定有：

- **NFS** (Network File System) - Linux/Unix 環境
- **CIFS/SMB** (Common Internet File System) - Windows 環境

### CIFS/SMB 掛載（Mount CIFS）

CIFS 是 Windows 檔案分享使用的協定，在 Linux 中可透過 `cifs-utils` 套件掛載。

#### 安裝必要套件

```bash
# Debian/Ubuntu
sudo apt install cifs-utils

# CentOS/RHEL
sudo yum install cifs-utils
```

#### 臨時掛載（單次使用）

```bash
sudo mount -t cifs -o username=someuser,password=somepass //192.168.0.110/backup /var/backup
```

#### 永久掛載（開機自動掛載）

編輯 `/etc/fstab`：

```bash
//192.168.0.110/backup /var/backup cifs username=someuser,password=somepass,network,iocharset=utf8,file_mode=0777,dir_mode=0777,noperm 0 0
```

##### 參數說明

| 參數             | 說明                    |
| ---------------- | ----------------------- |
| `username`       | CIFS 伺服器的使用者名稱 |
| `password`       | 使用者密碼              |
| `network`        | 支援網路掛載            |
| `iocharset=utf8` | 解決中文編碼問題        |
| `file_mode=0777` | 檔案權限                |
| `dir_mode=0777`  | 目錄權限                |
| `noperm`         | 忽略本地端的權限檢查    |

#### 安全性提升（使用 credential 檔案）

避免密碼明文顯示在 fstab 中：

```bash
# 建立 credential 檔案
sudo mkdir -p /etc/smb-credentials
sudo nano /etc/smb-credentials
```

填入以下內容：

```
username=someuser
password=somepass
domain=WORKGROUP
```

設定權限：

```bash
sudo chmod 600 /etc/smb-credentials
```

修改 `/etc/fstab`：

```
//192.168.0.110/backup /var/backup cifs credentials=/etc/smb-credentials,network,iocharset=utf8,file_mode=0777,dir_mode=0777,noperm 0 0
```

### NFS 掛載（Mount NFS）

NFS 是 Linux/Unix 環境中最常用的網路檔案系統協定。

#### 安裝必要套件

```bash
# Ubuntu/Debian
sudo apt install nfs-common

# CentOS/RHEL
sudo yum install nfs-utils
```

#### 臨時掛載

```bash
sudo mount -t nfs 192.168.0.110:/shared /var/nfs-mount
```

#### 永久掛載

編輯 `/etc/fstab`：

```
192.168.0.110:/shared /var/nfs-mount nfs defaults,_netdev 0 0
```

##### 常用 NFS 掛載選項

| 選項       | 說明                               |
| ---------- | ---------------------------------- |
| `defaults` | 使用預設選項                       |
| `_netdev`  | 等待網路啟動後再掛載               |
| `rw`       | 讀寫權限                           |
| `ro`       | 唯讀權限                           |
| `soft`     | 掛載失敗時返回錯誤（適合開機掛載） |
| `hard`     | 掛載失敗時持續重試                 |

## 權限問題處理

### CIFS 掛載後權限問題

常見問題：掛載後無法寫入，檔案擁有者變成 root。

#### 方法一：指定 UID/GID

```bash
//192.168.0.110/backup /var/backup cifs username=user,password=pass,uid=1000,gid=1000,file_mode=0755,dir_mode=0755 0 0
```

#### 方法二：使用 noperm（不推薦用於敏感資料）

```bash
//192.168.0.110/backup /var/backup cifs username=user,password=pass,noperm 0 0
```

### 驗證掛載成功

```bash
# 查看掛載點
df -h | grep -E "cifs|nfs"

# 測試寫入
touch /var/backup/test.txt

# 查看掛載選項
mount | grep /var/backup
```
