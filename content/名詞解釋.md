# 名詞解釋

## 編程範式

| 名詞                                   | 說明         | 代表語言                |
| -------------------------------------- | ------------ | ----------------------- |
| [[OOP]] (Object-oriented Programming)  | 物件導向編程 | C++, Java, PHP          |
| [[FP]] (Functional Programming)        | 函數式編程   | Haskell, Scheme, Erlang |
| [[AOP]] (Aspect Oriented Programming)  | 切面編程     | AspectJ                 |
| COP (Concurrency Oriented Programming) | 並發編程     | Elixir, [[Go]]          |

- [Programming Paradigms](https://sites.google.com/site/javacodelibrary/mda-tools/programming-paradigms)

## 設計模式

| 名詞                           | 說明                                   |
| ------------------------------ | -------------------------------------- |
| [[DI]] (Dependency Injection)  | 依賴注入，將依賴物件外部注入，降低耦合 |
| [[IoC]] (Inversion of Control) | 控制反轉，程式控制權由框架接管         |
| [[IOC Container]]              | 依賴注入容器，管理物件生命周期         |

- [簡單理解依賴注入與控制反轉](https://learnku.com/articles/5222/simply-explain-what-dependency-injection-and-control-inversion-are)
- [依賴注入借用容器](https://m.php.cn/article/302.html)
- [依賴注入詳解](https://juejin.im/post/5baeeb5be51d450e99433e57)

## 命名規則

| 規則        | 範例           | 適用場景         |
| ----------- | -------------- | ---------------- |
| Camel Case  | `myVariable`   | 變數、函式       |
| Pascal Case | `MyClass`      | 類別、介面       |
| Snake Case  | `my_variable`  | 變數、資料庫欄位 |
| Kebab Case  | `my-component` | CSS 類名、URL    |

- [命名規則](https://dustinhsiao21.com/2019/03/14/naming-convention/)（連結已失效）
