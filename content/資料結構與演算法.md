# 效能分析

這邊蠻重視數學的
log？n 次方程式？

- 時間複雜度
  編譯時間 + Input 所影響的時間
  一般來講就是程式預計要走幾步
  - 大寫的英文字母 O（Big O）函數，代表演算法執行步驟數目上限
  - 大寫的希臘字母 Ω（Omega）函數，代表下限
  - 大寫的希臘字母 Θ（Theta）函數，代表同時滿足上限與下限
    那我們通常用的是 O
    f(n) <= cg(n)

- 空間複雜度（佔用多少記憶體）
  Code 的大小 + Input 的量所影響的空間

# 陣列

定義：一組索引（Index）和值（Value）的集合
資料結構：一個索引對應一個值
實作：在電腦裡面用連續空間來存放
應用例子：矩陣、多項式、字串

# Stack（Last In First Out List）

定義：有限的元素
實作：用陣列來實作
應用例子：老鼠走迷宮

# Queue（First In First Out List）

定義：有限的元素，多了兩個變數指向 Front 前面、Rear 後面
實作：用陣列來實作
應用例子：Job Scheduling

# Circular Queue

定義：實質上還是一長列的 Queue
實作：用 Queue 實現
好處：充分利用空間
