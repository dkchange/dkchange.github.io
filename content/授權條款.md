# 心得

附一下子自己的理解，
[[GitHub]] 上項目可以選擇的協議有很多，其中

- None / No License
  就是作者完全保留這個源碼的所有權，不允許他人進行複製、分發、使用和修改，這時候就千萬不要去動他，用都不要用

知名的**開源**條款，可以修改的意思，但都需要**保留著作權訊息**

- [[GPL]] 最有開源精神，有使用就要開源，要說改了什麼
- [[LGPL]] 沒有修改，只有使用可以不必開源
- [[Apache]] 可不必開源，要說改了什麼
- [[BSD]] 可不必開源
- [[MIT]] 可不必開源，最自由

以上都可以修改，但要怎麼改，要不要備註作者名，要不要註明改什麼？改完之後你的 code 被強迫為何種 License？就要看詳細規定

最佛心的

- The Unlicense
  隨便你用
