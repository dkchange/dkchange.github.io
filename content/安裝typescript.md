# 用 npm 安裝 TypeScript

要用 [[npm]] 全域安裝 [[TypeScript]]：

```bash
npm install -g typescript
```

接著檢查版本：

```bash
tsc -v
```

看到版本號就是安裝成功！

> 小知識：`tsc` 是 TypeScript Compiler 的縮寫，用來將 .ts 檔案編譯成 .js 檔案
